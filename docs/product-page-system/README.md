# OVBEL 产品详情页创建体系

本目录记录可持续创建 OVBEL 多语言产品详情页的标准方法。它既适用于从旧网站迁移产品，也适用于完全从零创建新产品页面。

## 文档索引

| 文档 | 使用者 | 用途 |
|---|---|---|
| `01-全新产品页创建提示模板.md` | 产品、内容、AI 协作者、开发 | 一份可复制使用的完整任务提示 |
| `02-产品资料采集模板.md` | 产品、销售、技术、内容 | 收集和审核产品事实及素材 |
| `03-产品详情页标准作业流程.md` | 开发、内容、QA | 从资料到上线的完整步骤 |
| `04-花纹输送带页面创建记录.md` | 维护者、审计人员 | 本次页面的变更、决策和验证记录 |

## 代码入口

- 产品与本地化数据：`lib/products.ts`
- 通用详情页组件：`components/ProductDetailPage.tsx`
- 产品技术视觉：`components/ProductVisual.tsx`
- 产品卡片：`components/ProductCard.tsx`
- 询盘表单：`components/InquiryForm.tsx`
- 多语言路由与 metadata：`app/[locale]/[[...path]]/page.tsx`
- 页面样式：`app/globals.css`

## 核心原则

1. 产品事实、编辑性文案和待确认字段必须分开。
2. 同一产品的语言版本共用稳定 slug。
3. 页面由数据模型驱动，不为单个产品复制整套 JSX。
4. 可选模块通过数据字段出现或隐藏。
5. 产品图片必须可追溯、与产品匹配并具有使用权。
6. 其他页面、询盘、SEO、结构化数据和相关产品需同步更新。
7. 发布前必须完成内容审核、构建、Cloudflare 打包和双语验收。
