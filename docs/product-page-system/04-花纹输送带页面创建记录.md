# 花纹输送带页面创建记录

> 产品：Chevron Conveyor Belt / 花纹输送带  
> 创建日期：2026-08-09  
> 英文 URL：`/en/products/conveyor-belts/chevron-conveyor-belt`  
> 中文 URL：`/zh/products/conveyor-belts/chevron-conveyor-belt`

## 1. 资料输入

- 原产品页：<https://www.respowerbelt.com/h-col-114.html>
- 产品文档包：`docs/product-pages/chevron-conveyor-belt/`
- 原站内容审计：应用、特点、花纹、规格、储运注意事项；
- 当前新站数据：`lib/products.ts` 中的初版花纹输送带记录。

原站在创建期间存在 HTTPS 证书域名不匹配，图片未能可靠迁移。正文依据已存档的公开索引和仓库既有盘点交叉核对。页面没有使用第三方供应商图片。

## 2. 页面目标

- 将初版通用详情页升级为真实、完整的产品信息页面；
- 让新增字段和模块可被后续产品复用；
- 保持中英文信息量一致；
- 衔接分类、相关产品和询盘；
- 保留原站事实并避免扩大技术声明。

## 3. 数据模型变更

`Product` 增加可选字段：

- `applicationIntro`
- `featureHeading`
- `patterns`
- `precautions`
- `inquiryChecklist`
- `seo`
- `sourceUrl`

基础字段保持兼容，其他 11 个产品无需立即补齐可选字段。

## 4. 页面模块

本次实现：

1. 产品面包屑；
2. 产品技术视觉和分类标识；
3. 本地化产品摘要、说明和关键参数；
4. 页面章节导航；
5. 应用说明和五类应用；
6. 五项产品特点；
7. 五项技术参数；
8. 六类花纹选择；
9. 四项储运注意事项；
10. 产品专属询盘清单；
11. 同分类相关产品；
12. Product JSON-LD。

## 5. 视觉决策

- 继续使用 OVBEL 深蓝、橙色和工业网格系统；
- 为花纹输送带增加 CSS 技术示意视觉，明确它是页面视觉而非未经审核的产品摄影；
- 六类花纹使用抽象示意和文字双重表达；
- 后续取得真实产品图后，可以扩展统一媒体字段替换主视觉，不需要重写页面结构；
- 页面采用模块化网格，移动端降为单列。

## 7. 内容限制

页面没有声明原资料未提供的覆盖胶等级、强度、层数、厚度、温度、耐介质性能、标准、认证、价格、库存或质保。

`0–40°` 使用参考值表达，并说明最终适用性需按物料与工况确认。
