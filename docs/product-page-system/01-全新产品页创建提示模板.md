# 全新产品页创建提示模板

下面的提示可直接交给 AI 或开发团队使用。它不依赖已有网页，可以从产品资料、数据表、图片、图纸和业务访谈开始创建页面。

## 1. 完整提示

```text
请在 OVBEL 网站中创建一个真实、可发布、支持英语和简体中文的产品详情页。

产品基础信息：
- 英文名称：[填写]
- 中文名称：[填写]
- 产品分类 slug：[填写，例如 conveyor-belts]
- 产品 slug：[填写，仅使用小写英文和连字符]
- 品牌：OVBEL
- 公司主体：Shandong Ovbel Industrial Co., Ltd.
- 目标客户：[填写]
- 主要应用：[填写]

可用资料：
- 产品技术数据表：[路径或链接]
- 产品图片：[路径或链接]
- 图纸或尺寸表：[路径或链接]
- 认证或检测报告：[路径或链接]
- 销售/技术访谈记录：[路径或链接]
- 参考页面：[可选；没有则留空]

实现要求：
1. 先建立资料审计表，把“已确认事实”“编辑性归纳”“待确认内容”分开。不得使用行业常见值补齐本产品缺失参数。
2. 生成信息量一致、表达自然的英文与简体中文内容。技术单位、标准、型号和品牌名保持准确。
3. 使用现有统一产品数据模型和 ProductDetailPage 组件，不复制一份产品专属页面结构。
4. 根据内容按需启用：应用、特点、技术参数、型号/花纹/材料选项、储运、安装、维护、下载、FAQ、询盘清单和相关产品模块。
5. 页面首屏突出产品名称、核心价值、关键参数和询盘入口；移动端同样完整可用。
6. 使用经审核的真实产品素材。没有真实图片时，允许使用明确的技术示意视觉作为临时展示，但不能把 AI 图或第三方图片冒充真实产品。
7. 为两种语言分别生成 title、description、canonical、hreflang、Open Graph 和 Product JSON-LD；没有真实价格时不得添加 offers。
8. 产品页新增后，同步检查产品中心、分类页、首页精选产品、页脚、站内导航、询盘预填、相关产品、站点地图和搜索入口。
9. 语言切换保持当前产品和必要查询参数。所有站内链接携带当前语言前缀。
10. 完成 TypeScript、生产构建、Cloudflare OpenNext 构建、响应式、无障碍和双语内容验证。
11. 生成创建记录，包含资料来源、字段映射、内容决策、代码变更、素材清单、验证结果和未决事项。

输出顺序：
A. 资料审计与缺失项
B. 页面信息架构
C. 双语最终文案
D. 数据模型与代码实现
E. 其他页面同步调整
F. SEO 与结构化数据
G. 验收结果
H. 创建记录与待办事项
```

## 2. 资料不完整时的提示补充

```text
资料不完整时请继续创建可安全发布的最小页面，但必须：
- 只显示已确认参数；
- 对参考范围使用 reference / 参考等限定词；
- 将缺失字段加入询盘清单或待办表；
- 不生成虚假的认证、性能、价格、库存或客户案例；
- 明确哪些模块因资料不足暂不展示。
```

## 3. 多型号产品的提示补充

```text
该产品包含多个型号。请把系列级事实与型号级参数分开：
- 页面首屏表达系列价值；
- 型号表必须使用稳定型号 ID；
- 单位和空值规则统一；
- 移动端提供可读布局；
- 不同型号差异可筛选或对比，但不要隐藏关键限制；
- 询盘时传递产品 slug 和所选型号 ID。
```

## 4. 全新产品而非旧站迁移时的资料优先级

1. 经技术负责人签字的正式数据表；
2. 产品图纸和型号表；
3. 检测或认证文件；
4. 经审核的产品摄影；
5. 产品经理、工程师和销售访谈；
6. 公司内部样本；
7. 供应商资料；
8. 行业标准，仅用于解释背景，不能自动变成本产品声明。
