# 产品详情页标准作业流程

## 阶段 1：建立产品档案

1. 复制 `02-产品资料采集模板.md`。
2. 确认英文名称、中文名称、分类和稳定 slug。
3. 登记所有资料来源及版本。
4. 由产品或技术负责人区分：
   - 已确认事实；
   - 参考范围；
   - 编辑性归纳；
   - 待确认内容；
   - 不得公开内容。
5. 建立素材权利记录。

产物：完整产品资料档案。

## 阶段 2：确定页面信息架构

所有页面至少包含：

- 面包屑；
- 产品名称、摘要和说明；
- 产品视觉；
- 特点；
- 技术参数；
- 应用；
- 询盘入口。

按资料启用可选模块：

- 型号、材料、花纹或结构选择；
- 储运；
- 安装与维护；
- 下载；
- FAQ；
- 认证；
- 案例；
- 相关产品。

不要为了保持页面长度而填充无依据内容。

## 阶段 3：编写双语内容

1. 先基于已确认事实写信息完整的主语言稿。
2. 翻译另一语言，不做逐词机械翻译。
3. 保持两种语言的参数、限制和模块一致。
4. 标准、型号、单位、商标和公司名保持原始准确形式。
5. 对范围值使用 Reference / 参考等限定词。
6. 页面标题说明产品是什么，摘要说明用途，正文说明结构与价值。
7. CTA 指向具体下一步，如“发送输送带需求”，避免只有“了解更多”。

产物：经业务审核的双语最终文案。

## 阶段 4：准备素材

1. 取得真实产品主图和结构/应用图片。
2. 核对图片确实属于该产品或型号。
3. 记录权利主体和审核人。
4. 输出 WebP/AVIF 发布版本并保留母版。
5. 编写两种语言的 alt。
6. 没有真实图时使用明确的技术示意视觉，并记录替换待办；不得使用竞争对手图片。

产物：审核后的素材清单和发布文件。

## 阶段 5：写入产品数据

在 `lib/products.ts` 或后续产品内容文件中：

1. 为英文 `products` 增加基础对象；
2. 为 `zhProducts` 增加中文覆盖；
3. 必填字段包括：
   - `slug`
   - `name`
   - `category`
   - `eyebrow`
   - `summary`
   - `description`
   - `features`
   - `applications`
   - `specifications`
4. 按需增加：
   - `applicationIntro`
   - `featureHeading`
   - `patterns`
   - `precautions`
   - `inquiryChecklist`
   - `seo`
   - `sourceUrl`
5. 保证两种语言可选字段结构对应。

产物：可由统一详情页组件读取的本地化数据。

## 阶段 6：页面与相关区域同步

通用 `ProductDetailPage` 会自动渲染基础和可选模块。新增数据后检查：

- 产品中心是否出现产品；
- 分类页是否出现产品；
- 产品卡片视觉和文案是否正确；
- 同分类相关产品是否正确；
- 首页精选是否需要调整排序或数量；
- 页脚分类是否需要调整；
- 询盘页是否显示本地化产品名和专属清单；
- 语言切换是否保留产品和查询参数；
- 站点地图、搜索索引或 CMS 索引是否需要更新。

产物：站内入口与转化链路完整。

## 阶段 7：SEO 与结构化数据

1. 填写两种语言的 `seo.title` 和 `seo.description`。
2. 检查 canonical 为当前语言 URL。
3. 检查 `en`、`zh-CN`、`x-default` hreflang。
4. Product JSON-LD 与可见内容一致。
5. 没有真实价格、库存、评分或评论时不添加相应字段。
6. 有审核图片后再加入结构化数据图片 URL。

产物：可索引且不误导的产品元数据。

## 阶段 8：技术验证

最低验证：

1. TypeScript 编译；
2. Next.js 生产构建；
3. Cloudflare OpenNext build；
4. 英文和中文 URL；
5. 无效语言和无效 slug 返回 404；
6. 320 px、720 px、1000 px 及桌面布局；
7. 键盘焦点、标题层级、alt 和对比度；
8. 询盘预填和邮件正文；
9. canonical、hreflang 和 JSON-LD；
10. 页面无断图、无无效链接、无阻断性控制台错误。

产物：验收记录。

## 阶段 9：记录与发布

为每个产品记录：

- 产品档案路径；
- 资料来源和版本；
- 数据字段映射；
- 页面模块；
- 素材来源；
- 代码修改；
- 同步调整页面；
- 构建结果；
- 未决事项；
- 提交哈希和发布日期。

发布属于外部操作，必须由拥有对应部署权限的人员或流程执行。
