# 03 — 实现规格

> 与现有 OVBEL 产品详情页实现保持一致，仅扩展 `lib/products.ts` 的数据模型；未新增组件、未新增路由。

## 1. 数据模型扩展

### 1.1 变更对象
- `lib/products.ts`：**新增** `steel-cord-conveyor-belt` 条目（EN，位于 `white-conveyor-belt` 之后、`anti-tear-conveyor-belt` 之前）+ `zhProducts["steel-cord-conveyor-belt"]`（ZH，位于 `white-conveyor-belt` 之后、`anti-tear-conveyor-belt` 之前）。

### 1.2 字段填充
| 字段 | 是否填充 | 来源 |
|---|---|---|
| `slug` / `name` / `category` | 是 | 原站栏目名与分类约定 |
| `eyebrow` / `summary` / `description` | 是 | 原站结构与性能描述，编辑性改写 |
| `features` | 是 | 原站 Heavy load / Transverse reinforcement / High tensile strength / Low extensibility |
| `applications` | 是 | 原站 Power / Chemical + 行业惯例 Mining / Ports / Metallurgy / Cement |
| `specifications` | 是 | 结构/性能/覆盖胶类型/参照标准，无具体数值 |
| `patterns` | 是 | 8 种覆盖胶类型 |
| `precautions` | 是 | 行业通用储运规范，编辑性改写 |
| `inquiryChecklist` | 是 | 围绕事实的询盘要素 |
| `seo` | 是 | title / description |
| `sourceUrl` | 是 | https://www.respowerbelt.com/h-col-136.html |
| `media` | 是 | 8 张真实 webp（4 张图库 + 4 张技术规格表） |

### 1.3 数字规格处理
- 所有 St 等级、钢丝绳根数、粘合力、带宽矩阵、覆盖胶性能指数等数值 **仅通过 `technicalImages` 中的 4 张规格表图片呈现**，未在文本中编写具体数值，避免编造参数。

## 2. 自动同步的能力

由于站点采用统一数据驱动渲染：
- 分类页 `/products/conveyor-belts` 自动出现该产品卡片；
- 产品卡片使用 `media.cover`、`summary`、`eyebrow`；
- 相关产品使用同分类其他产品；
- 询盘表单预填 `product=steel-cord-conveyor-belt`；
- `ProductDetailPage` 自动输出 canonical、hreflang（en / zh-CN / x-default）、Open Graph、Product JSON-LD。
