## 产品一句话
以新型钢丝绳为张力元件（单侧或双侧铺设横向钢丝增强层）的高强度输送带，高拉伸强度、低伸长率、可配小滚筒，按覆盖胶特性分为通用/阻燃/耐寒/耐磨/耐热/耐酸碱/耐油等类型，用于煤矿、矿石港口、冶金、电力、化工等重载长距离输送。
