# 03 — 实现规格

> 与现有 OVBEL 产品详情页实现保持一致，仅扩展 `lib/products.ts` 的数据模型；未新增组件、未新增路由。

## 1. 数据模型扩展

### 1.1 变更对象
- `lib/products.ts`：**新增** `fire-resistant-conveyor-belt` 条目（EN，位于 `anti-tear-conveyor-belt` 之后、`ep-nylon-conveyor-belt` 之前）+ `zhProducts["fire-resistant-conveyor-belt"]`（ZH，位于 `anti-tear-conveyor-belt` 之后、`ep-nylon-conveyor-belt` 之前）。

### 1.2 字段填充
| 字段 | 是否填充 | 来源 |
|---|---|---|
| `slug` / `name` / `category` | 是 | 原站栏目名与分类约定 |
| `eyebrow` / `summary` / `description` | 是 | 原站结构与性能描述，编辑性改写 |
| `features` | 是 | 原页带芯、工艺、阻燃、导静电、适用环境等特性 |
| `applications` | 是 | 原页 power / chemical / light / metallurgical / grain，补充煤矿 |
| `specifications` | 是 | 覆盖胶性能、安全性能、阻燃等级（来自原页表格） |
| `patterns` | 是 | 9 种国际阻燃等级 / 标准型号 |
| `precautions` | 是 | 行业通用储运规范，编辑性改写 |
| `inquiryChecklist` | 是 | 围绕事实的询盘要素 |
| `seo` | 是 | title / description |
| `sourceUrl` | 是 | https://www.respowerbelt.com/h-col-135.html |
| `media` | 是 | 2 张真实 webp（1 张封面 + 1 张图库） |

### 1.3 数字规格处理
- 覆盖胶拉伸强度、拉断伸长率、磨耗量，以及阻燃等级、火焰持续时间、抗静电性能等数值 **均来自原页 HTML 表格**，以文本规格形式呈现。
- 具体带宽、带长、覆盖胶厚度、工作温度、最大带速、最小带轮直径等原站未给出数值，**未在页面中编造**。

## 2. 自动同步的能力

由于站点采用统一数据驱动渲染：
- 分类页 `/products/conveyor-belts` 自动出现该产品卡片；
- 产品卡片使用 `media.cover`、`summary`、`eyebrow`；
- 相关产品使用同分类其他产品；
- 询盘表单预填 `product=fire-resistant-conveyor-belt`；
- `ProductDetailPage` 自动输出 canonical、hreflang（en / zh-CN / x-default）、Open Graph、Product JSON-LD。
