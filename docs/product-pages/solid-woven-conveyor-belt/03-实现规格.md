# 实现规格：整芯输送带

## 数据模型
- 文件: `lib/products.ts`
- 位置: `products[]` 数组内，插入 `sidewall-conveyor-belt` 之后、`transmission-flat-belt` 之前
- 中文本地化: `zhProducts{}` 末尾新增 `"solid-woven-conveyor-belt"` 键

## 字段覆盖
- slug / name / category / eyebrow / summary / description / applicationIntro / featureHeading / features / applications / specifications / patterns / precautions / inquiryChecklist / seo / sourceUrl / media
- 所有字段均提供英文（products[]）和中文（zhProducts{}）版本，信息量保持一致

## 渲染方式
- 复用既有 `ProductDetailPage`、`ProductGallery`、`ZoomableImage` 组件
- 无新增页面路由或组件文件
- 图库包含 5 张产品图 + 1 张规格表图；`cover` 同时作为分类页产品卡片封面
- Product JSON-LD 由 `ProductDetailPage` 自动输出，包含 name、description、image、brand、manufacturer；不含虚构的 offers / rating

## 关联更新
- 分类页 `/products/conveyor-belts` 自动列出新产品（数据驱动）
- 产品卡片使用 `media.cover` 作为缩略图
- 相关产品使用同分类数据自动推荐
- 询盘表单通过 `inquiryChecklist` 预填主题
- SEO / canonical / hreflang / Open Graph 由 `[locale]/[[...path]]/page.tsx` 统一输出
- 语言切换保持当前 slug 和查询参数

## 响应式与无障碍
- 图库与详情页沿用 Tailwind 响应式断点
- 图片可点击全屏放大，无放大镜装饰图标
- 所有图片提供 alt 文本
- 焦点样式与对比度沿用项目既有组件标准
