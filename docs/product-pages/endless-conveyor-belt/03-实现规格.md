# 03 - 实现规格（Endless Conveyor Belt）

## 1. 实现目标

在 OVBEL 网站新增一个**真实、可上线、支持中英文**的环形输送带详情页，复用现有数据驱动架构，不新建重复页面。

## 2. 路由与多语言

- 详情页由既有 catch-all 路由 `app/[locale]/[[...path]]/page.tsx` 数据驱动渲染，`locale ∈ {en, zh}`。
- 分类页、产品卡片、相关产品、询盘预填均经 `lib/products.ts` 的 `getProducts(locale)` / `getLocalizedProductsByCategory` / `getLocalizedProduct` 自动派生。
- 语言切换（`components/SiteHeader.tsx`）沿用 `usePathname` + `useSearchParams`，**保持当前产品路径与查询参数（如 `?product=endless-conveyor-belt`）**。

## 3. 数据模型扩展（唯一改动点）

仅扩展 `lib/products.ts`，**未新建组件/路由/页面**：

- EN：在 `products: Product[]` 中新增一项（slug `endless-conveyor-belt`，category `conveyor-belts`），置于既有条目之后。
- ZH：在 `zhProducts` 中新增同名 key 的 override（省略 `slug`/`category`），置于既有条目之后、闭合 `};` 之前。
- 字段集与既有条目一致：`name, eyebrow, summary, description, applicationIntro, featureHeading, features[], applications[], specifications[], precautions[], inquiryChecklist[], seo{title,description}, sourceUrl, media{cover, gallery[], galleryAlt[]}`。

## 4. 组件需求（复用既有，无需改动）

| 组件 | 职责 | 是否满足要求 |
|---|---|---|
| `ProductDetailPage.tsx` | 数据驱动渲染；按需展示图库/简介/优势/应用/规格/型号花纹(织法)/储运/询盘清单/相关产品；自动注入 Product JSON-LD | 满足 4/6 |
| `ProductGallery.tsx` + `ZoomableImage.tsx` | 点击全屏放大灯箱（键盘 Esc/←/→），**无放大镜装饰图标** | 满足 7 |
| `ProductCard.tsx` | 自动渲染 cover + 链接到详情 | 满足 6（分类页/卡片） |
| `InquiryForm.tsx` | 经 `?product=slug` 预填询盘 | 满足 6 |
| `SiteHeader.tsx` | 语言切换保留路径+查询 | 满足 5 |

## 5. Metadata / JSON-LD（自动）

- `generateMetadata`（catch-all 路由）基于 `seo` 自动生成 `title/description`、`canonical`、`hreflang`（en / zh-CN / x-default）、Open Graph。
- `ProductDetailPage` 自动注入 `Product` 类型 JSON-LD（含 name、image、description、category 等）。
- 新增条目后上述全部自动覆盖，无需手写。

## 6. 性能与可访问性（沿用既有实现）

- 图片为 webp（cover 7.4 KB、gallery-01 12.7 KB、gallery-02 3.4 KB），体积可控。
- 响应式：既有组件已覆盖桌面 + 移动端。
- 键盘操作、alt 文本、焦点样式、对比度：沿用既有组件；本次为新增图片补全 `galleryAlt`（英文/中文各 3 条）。
