## 3. 已提取事实（Confirmed）

### 3.1 特性（Features）
- 环形（无接头）结构消除接头处早期损坏风险，使用寿命更长。
- 表面平整、张力均匀，运行平稳、使用中伸长率小。
- 提供两种型号：高强度型（high-strength）与标准型（standard）。
- 采用特殊浸渍与模压材料，层间粘合强度优异。
- 带芯为高通强尼龙、聚酯或棉帆布。
- 覆盖胶弹性好、抗冲击、抗撕裂、耐磨性能优异。
- 适用于中小型带式输送机。
- 无需现场接头（无现场硫化）：直接套装于托辊即可运行，节省时间。

### 3.2 应用（Applications，来自「Product Description / Characteristics」）
- 适用于中等距离、中等负荷的粉状、粒状及小块物料输送。
- 行业：矿山、煤矿、港口、冶金、化工、建筑、电站等。

### 3.3 织物组合代号（Fabric Combination）
| 代号 | 含义 |
|---|---|
| EP | Polyester / Polyamide（聚酯/聚酰胺） |
| TC | Polyester / Cotton（聚酯/棉） |
| NN | Polyamide(Nylon) / Polyamide(Nylon)（尼龙/尼龙） |
| EPP | Polyester / Polyamide / Polyamide（SW-diameter） |
| CC | Cotton / Cotton（棉/棉） |
| XE | Monofilament / Polyester（单丝/聚酯） |

### 3.4 织法（Weaving）
- 1–6 层；平纹（plain weave）、CFW、人字纹（rib weave）、破斜纹（broken twill weave）。

### 3.5 规格参数（Specifications）
- 抗拉强度：100–800 kN/m/ply
- 带宽：300–2500 mm
- 覆盖胶厚度：1.5–30 mm
