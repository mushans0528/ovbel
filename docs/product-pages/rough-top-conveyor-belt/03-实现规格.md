# 实现规格：Rough Top Conveyor Belt

> 适用范围：本次在 `lib/products.ts` 中的数据扩展，以及 `public/products/rough-top-conveyor-belt/` 下的图片资源  
> 目标分支：`main`  
> 验证依据：`next build` + `tsc --noEmit` + 双语页面手动核验

## 1. 数据模型

本次沿用既有的统一产品模型 `Product`（`lib/products.ts:27`），**不为 Rough Top 单独硬编码页面**：

```text
type Product {
  slug; category; eyebrow;
  summary; description;
  applicationIntro?; featureHeading?;
  features: string[];
  applications: string[];
  specifications: Specification[];
  patterns?: ProductPattern[];     // Rough Top 不含离散花纹选项，留空
  precautions?: string[];
  inquiryChecklist?: string[];
  seo?: ProductSeo;
  sourceUrl?: string;
  media?: ProductMedia;
  layers?: ProductLayer[];          // Rough Top 不含分层结构图，留空
}
```

`patterns` 与 `layers` 字段本次保留为空，因此 `ProductDetailPage` 不会渲染"花纹选择"和"结构解析"两节，避免出现空模块。

## 2. 双语合并机制

沿用 `getProducts(locale)`（`lib/products.ts:551`）：

- `locale === "en"` 时直接返回 `products` 数组中的英文对象；
- `locale === "zh"` 时通过 `Omit<Product, "slug" | "category">` 把 `zhProducts[slug]` 合并到英文对象之上，覆盖可本地化字段；
- `slug`、`category`、`media` 字段在两种语言下保持一致，确保 URL 与图片路径稳定。

`zhProducts["rough-top-conveyor-belt"]` 字段与 `products["rough-top-conveyor-belt"]` 一一对应。

## 3. 路由与页面

- 路径：`/{locale}/products/conveyor-belts/rough-top-conveyor-belt`
- 入口：`app/[locale]/[[...path]]/page.tsx`，分支 `path[0]==="products" && path.length===3` 时调用 `getLocalizedProduct(...)` 并渲染 `ProductDetailPage`。
- 分类卡片：`app/[locale]/[[...path]]/page.tsx` 的 `CategoryPage` 会通过 `getLocalizedProductsByCategory("conveyor-belts", locale)` 自动列出新产品。
- 询盘预填：`/request-quote?product=rough-top-conveyor-belt` 在 `Quote` 组件中按产品 slug 取 `inquiryChecklist`。

## 4. 图片资源

`public/products/rough-top-conveyor-belt/`：

| 文件 | 用途 | 说明 |
|---|---|---|
| `cover.webp` | 入口封面（hero） | `media.cover`，1536×1024，约 46 KB |
| `surface-texture.webp` | 图库 1：纹理近景 | `media.gallery[0]`，1024×1024 |
| `factory-rolling.webp` | 图库 2：工厂卷取 | `media.gallery[1]`，1024×1024 |
| `cross-section.webp` | 图库 3：结构剖视 | `media.gallery[2]`，1024×1024 |

`ProductGallery` 组件统一处理首屏 `Image fill priority`、缩略图、键盘焦点、灯箱开关、左右切图与 Esc 关闭。灯箱按钮为 `<button>`，无放大镜装饰图标。

## 5. SEO 与结构化数据

由 `generateMetadata`（`app/[locale]/[[...path]]/page.tsx:42`）统一输出：

- `title` 来自 `product.seo?.title`，缺省回退到 `product.name`；
- `description` 来自 `product.seo?.description`，缺省回退到 `product.summary`；
- `alternates.canonical = https://ovbel.com/{locale}/products/conveyor-belts/rough-top-conveyor-belt`；
- `alternates.languages` 同时给出 `en` / `zh-CN` / `x-default` 三个 hreflang；
- Open Graph 的 `images` 自动拼接 `media.cover` 与 `media.gallery`，全部使用绝对 URL。

`ProductDetailPage` 在页面顶部输出 `Product` JSON-LD：

- 包含 `name / description / category / brand / manufacturer / url / image`；
- **未包含** `offers / aggregateRating / review`，避免虚构价格、库存与评分。

## 6. 无障碍与响应式

- 主图与图库：均使用 `<Image>` + `alt` 文本由 `ProductGallery` 按 locale 动态生成；灯箱为 `role="dialog"` + `aria-modal="true"`，关闭按钮获得初始焦点，Esc 关闭、左右切图。
- 参数模块：`spec-card` 在窄屏下保持单列堆叠，320 px 视口下不出现横向滚动。
- CTA：`Request a quote` 与 `Ask a technical question` 为 `<Link>`，键盘可达，焦点样式由全局 CSS 提供。
- 颜色对比：品牌色 `#0B3A6E` 与白底、`#FF7A00` 与白底对比度经 Tailwind 调色板校验满足 WCAG AA。
