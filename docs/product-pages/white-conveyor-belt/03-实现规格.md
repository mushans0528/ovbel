## 3. 路由与 SEO
- 详情页路由：`/products/conveyor-belts/white-conveyor-belt`（en）/ `/zh/products/conveyor-belts/white-conveyor-belt`（zh），由 `app/products/[category]/[slug]/page.tsx` 与 `app/[locale]/[[...path]]/page.tsx` 通用路由处理，无需修改。
- `canonical` / `hreflang`（en, zh-CN, x-default）/ `Open Graph` / `Product JSON-LD` 由既有路由组件基于 `seo` 字段自动输出，无需修改。
- 不含 `offers` / `aggregateRating`（不虚构价格/库存/评分），与既有约定一致。

## 4. 多语言与查询参数
- EN/ZH 信息量一致（eyebrow/summary/description/features/applications/specifications/layers/precautions/inquiryChecklist/seo 全部对齐）。
- 询盘表单预填：`subject` 自动填入产品名 + 询盘条目；语言切换后产品 slug 与询盘条目同步切换（由既有 `getProducts(locale)` 与表单内部读取实现）。

## 5. 关联产品
- 同一分类（`conveyor-belts`）其它产品自动作为"相关产品"渲染：chevron / elevator / rough-top / sidewall / solid-woven。
- 不强制 5 个，超出/不足均保留现有渲染逻辑。
