# 03 — 实现规格

> 与现有 OVBEL 产品详情页实现保持一致，仅扩展 `lib/products.ts` 的数据模型；未新增组件、未新增路由、未新增产品条目（`transmission-flat-belt` 已存在，本次为内容扩充）。

## 1. 数据模型扩展

### 1.1 变更对象
- `lib/products.ts`：**修改既有** `transmission-flat-belt` 条目（EN）与 `zhProducts["transmission-flat-belt"]`（ZH）。
- 变更前：EN 仅 eyebrow/summary/description/features(3)/applications(3)/specifications(3)，无 patterns/precautions/inquiryChecklist/seo/sourceUrl/media；ZH 为单行精简数据。
- 变更后：补全 h-col-121 全部内容（见下）。

## 2. 组件复用
| 组件 | 用途 | 是否修改 |
|---|---|---|
| `ProductDetailPage` | 详情页主框架，数据驱动 | 否 |
| `ProductGallery` | 主图库（点击全屏灯箱，键盘 Esc/左右） | 否 |
| `ZoomableImage` | 规格表等内嵌图的点击放大（无放大镜图标） | 否 |
| `ProductCard` | 卡片视图（首页、分类页、相关产品） | 否 |
| `InquiryForm` | 询盘表单，自动预填产品名与询盘条目 | 否 |

## 3. 路由与 SEO
- 详情页路由：`/products/power-transmission-belts/transmission-flat-belt`（en）/ `/zh/products/power-transmission-belts/transmission-flat-belt`（zh），由既有通用路由处理，无需修改。
- `canonical` / `hreflang`（en, zh-CN, x-default）/ `Open Graph` / `Product JSON-LD` 由既有组件基于 `seo` 自动输出。
- 不含 `offers` / `aggregateRating`（不虚构价格/库存/评分）。

## 4. 多语言与查询参数
- EN/ZH 信息量一致（description/features/applications/specifications/patterns/precautions/inquiryChecklist/seo 全部对齐，数量一致）。
- 术语：源页 "Round edge" → 中文"圆边"（由旧数据"包边"统一，见 01 审计 §五）。
- 语言切换保持当前产品 slug 与询盘条目（既有 `getProducts(locale)` 实现）。

## 5. 关联产品
- 同一分类（`power-transmission-belts`）另一产品 `industrial-v-belt` 自动作为相关产品渲染；分类页自动包含本产品卡片。
