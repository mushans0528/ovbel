# 实现规格

## 1. 实现目标

在现有 Next.js 多语言架构内，新增聚酯芯输送带产品详情页，使其与 chevron、ep-nylon 等既有产品共用同一渲染组件，包含以下模块：

1. 面包屑；
2. 产品图（含全屏可点击放大）与双语首屏；
3. 应用说明；
4. 产品特点；
5. 技术参数；
6. 储运注意事项；
7. 产品专属询盘入口；
8. SEO metadata、hreflang 与 Product JSON-LD；
9. 相关产品（数据驱动）。

不得为该产品新建与现有路由平行的硬编码页面。内容继续由统一产品数据模型驱动。

## 2. 路由与语言

- 路由继续使用 `app/[locale]/[[...path]]/page.tsx` 的 catch-all 与 `generateMetadata`。
- `locale` 仅允许 `en`、`zh`。
- 产品 slug 在两种语言下保持 `polyester-core-conveyor-belt`。
- 英文页语言为 `en`；中文页根文档语言为 `zh-CN`。
- 切换语言时保留分类和产品 slug（由 `SiteHeader` 中 `usePathname` + `useSearchParams` 拼接的 `/${otherLocale}${suffix}?${query}` 实现）。
- 带 `?product=polyester-core-conveyor-belt` 的询盘链接在语言切换时也应保留查询参数。
- 非本地化回退路由 `app/products/[category]/[slug]/page.tsx` 由 `generateStaticParams` 自动包含本产品，渲染使用通用产品模板，无需单独维护。

## 3. 数据模型扩展

未修改 `Product` 类型。仅在 `lib/products.ts` 中：

- `products[]` 末尾（ep-nylon 之后、transmission-flat 之前）追加英文产品对象；
- `zhProducts` 末尾追加中文覆盖对象（key = `polyester-core-conveyor-belt`）。

`ProductMedia.galleryAlt` 在中文覆盖对象中显式给出本地图例，以保证 lightbox alt 在中文页为中文。

## 6. 页面组件要求

### 6.1 产品首屏

- 桌面端采用图与摘要双栏；移动端单列。
- 主图为规格表图，带双语 alt；点击进入全屏 lightbox，无放大镜装饰图标。
- 主按钮指向当前语言的 `/request-quote?product=polyester-core-conveyor-belt`。
- 摘要附近展示"最终规格按应用确认"的短提示。

### 6.2 特点、参数

- 特点使用语义化 `ul/li`。
- 参数使用 `dl/dt/dd`（由 `ProductDetailPage` 统一渲染）。
- 数值和单位之间采用一致格式，如 `400–2500 mm`、`4–25 mm`。

### 6.3 储运说明

- 独立于产品卖点展示，标题明确为 Handling and storage / 运输与储存。
- 不要把储运注意事项写入 features 数组。

### 6.4 询盘

- 首期沿用邮件询盘，邮件正文加入产品专属字段。
- 用户从产品页进入询盘时，产品名称按当前语言显示，同时传递稳定 slug。
- 询盘预填链路：`/request-quote?product=polyester-core-conveyor-belt` → `Quote` 组件 `getProducts(locale).find(...)` → `InquiryForm` 的 `defaultProduct` 与 `productSlug`。

## 7. Metadata 与结构化数据

- `generateMetadata` 在 `app/[locale]/[[...path]]/page.tsx` 已对 `path.length === 3` 的产品页生成：
  - `title = product.seo?.title || product.name`
  - `description = product.seo?.description || product.summary`
  - `alternates.canonical = https://ovbel.com/${locale}/products/${category}/${slug}`
  - `alternates.languages = { en, zh-CN, x-default }`
  - `openGraph = { title, description, url, images: [cover, ...gallery] }`
- Product JSON-LD 在 `components/ProductDetailPage.tsx` 注入，包含 `name`、`description`、`category`、`brand=OVBEL`、`manufacturer=Shandong Ovbel Industrial Co., Ltd.`、`url`、来自 `cover + gallery` 的 `image` 列表。
- 没有真实价格和库存时，不添加虚假的 `offers`。
- OG 图与 JSON-LD image 引用同一份 `cover.webp`，URL 形如 `https://ovbel.com/products/polyester-core-conveyor-belt/cover.webp`。

## 8. 性能与无障碍

- 主图使用 Next.js `Image` 并提供准确宽高，避免布局偏移。
- 首屏主图可 `priority`，其余图片延迟加载。
- 正文与背景对比度满足 WCAG AA。
- 键盘用户可以访问图片查看（`ProductGallery` 主图按钮为 `<button>`，Esc 关闭，方向键切换）和 CTA。
- 移动端参数表不得产生不可控的横向溢出。
- 切换语言时保留当前产品 slug 与查询参数。

## 9. 推荐实施顺序

1. 下载并命名唯一的真实素材（规格表图） → `public/products/polyester-core-conveyor-belt/cover.webp`；

4. 运行 `npm run build` 与 TypeScript 检查；
5. 补充本产品档案目录（README + 5 个正文文档）；
6. 提交并尝试推送。
