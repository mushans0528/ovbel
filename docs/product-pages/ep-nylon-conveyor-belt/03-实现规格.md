# 03 — 实现规格

> 与现有 OVBEL 产品详情页实现保持一致，仅扩展 `lib/products.ts` 的数据模型；未新增组件、未新增路由。

## 1. 数据模型扩展

### 1.1 变更对象
- `lib/products.ts`：**新增** `ep-nylon-conveyor-belt` 条目（EN，位于 `anti-tear-conveyor-belt` 之后、`transmission-flat-belt` 之前）+ `zhProducts["ep-nylon-conveyor-belt"]`（ZH，位于 `anti-tear-conveyor-belt` 之后、`};` 之前）。

### 1.2 字段填充
| 字段 | 是否填充 | 来源 |
|---|---|---|
| `slug` / `name` / `category` | 是 | 原站栏目名与分类约定 |
| `eyebrow` / `summary` / `description` | 是 | 原站 EP/NN 结构与性能描述，编辑性改写 |
| `features` | 是 | 原站 EP 低伸长、NN 耐磨/耐疲劳等特性 |
| `applications` | 是 | 原站 mine / ports / metallurgy / building / chemical / electric power / grain |
| `specifications` | 是 | 结构/性能范围，数值类标注“详见技术图片”或“需确认” |
| `patterns` | 是 | 4 个系列分组（EP 轻/重、NN 轻/重） |
| `precautions` | 是 | 行业通用储运规范，编辑性改写 |
| `inquiryChecklist` | 是 | 围绕事实的询盘要素 |
| `seo` | 是 | title / description |
| `sourceUrl` | 是 | https://www.respowerbelt.com/h-col-125.html |
| `media` | 是 | 4 张真实 webp（2 张图库 + 2 张技术规格表） |

### 1.3 数字规格处理
- EP / NN 强度矩阵、单层厚度、覆盖胶厚度、带宽与卷长等数值 **仅通过 `technicalImages` 中的 2 张规格表图片呈现**，并在文本中给出范围概览，未编造具体默认值。
- 文本规格中所有范围均来自原页规格表图片核对：
  - EP 强度 160–3000 N/mm，NN 强度 200–3000 N/mm；
  - 带宽 400–2500 mm；
  - 卷长 ≤ 300–500 m。

## 2. 自动同步的能力

由于站点采用统一数据驱动渲染：
- 分类页 `/products/conveyor-belts` 自动出现该产品卡片；
- 产品卡片使用 `media.cover`、`summary`、`eyebrow`；
- 相关产品使用同分类其他产品；
- 询盘表单预填 `product=ep-nylon-conveyor-belt`；
- `ProductDetailPage` 自动输出 canonical、hreflang（en / zh-CN / x-default）、Open Graph、Product JSON-LD。
