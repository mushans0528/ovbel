# 03 - 实现规格

## 架构复用

- 分类：复用 `conveyor-components`
- slug：新增 `belt-fastener`（仓库中不存在同名产品）
- 路由：复用 `/[locale]/products/[category]/[slug]`
- 详情页：复用 `ProductDetailPage`
- 分类卡片：复用 `ProductCard`
- 询盘：复用 `InquiryForm`
- 图库/放大：复用 `ProductGallery` 与 `ZoomableImage`

## 数据模型

本产品仅使用现有 `Product` 字段，未为单一产品创建专用页面或特判逻辑：

- 必填基础字段
- `applicationIntro`
- `featureHeading`
- `precautions`
- `inquiryChecklist`
- `seo`
- `sourceUrl`
- `patterns`
- `media.gallery` / `galleryAlt`
- `media.technicalImages` / `technicalImageLabels`

## 自动级联

- 英文与中文详情路由自动生成。
- `conveyor-components` 分类页自动出现产品卡片。
- 同分类相关产品自动生成。
- `/request-quote?product=belt-fastener` 自动预填产品名与询盘清单。
- canonical、hreflang、Open Graph 由统一 metadata 逻辑生成。
- Product JSON-LD 由 `ProductDetailPage` 生成，不包含价格、库存、评分或 offers。
