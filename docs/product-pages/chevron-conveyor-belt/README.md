## 1. 文档用途

本目录包含实现一份中英文产品详情页所需的内容事实、双语文案、数据结构、页面模块、SEO、素材清单和验收标准。

建议按以下顺序使用：

1. 内容或产品负责人审核 `01-原站内容审计.md` 中的事实和待确认项；
2. 翻译或业务负责人审核 `02-双语页面文案.md`；
3. 开发人员依据 `03-实现规格.md` 扩展数据模型和页面模块；
4. 设计或内容人员依据 `04-素材与SEO规范.md` 准备图片；
5. 测试人员依据 `05-验收清单.md` 验收中英文页面。

## 3. 文档边界

- 原页面可核实的事实被标记为“原站事实”。
- 为提高可读性而改写的句子被标记为“编辑性改写”，不得改变参数含义。
- 原站未提供的技术数据被标记为“待确认”，上线前不得编造。
- 本文档不授权使用第三方搜索结果中的替代产品图片。
- 原站图片因旧站 HTTPS 证书异常未能可靠导出，必须由站点所有者从原 CMS、服务器或原始图库取得。

当前 `lib/products.ts` 已有产品名称、摘要、说明、三项特点、三类应用和四项规格，但缺少：

- 第四项特点：排水性能；
- 六类常见花纹；
- 完整储运注意事项；
- 带芯材料的全称说明；
- 产品图片和图片无障碍文本；
- 面向该产品的结构化询盘字段；
- 更完整的产品专属 SEO 文案和结构化数据。

## 5. 推荐发布策略

第一阶段可以用已确认的原站参数发布，同时增加“最终规格以应用审核和报价确认为准”的提示。覆盖胶等级、拉伸强度、层数、厚度、耐温、耐油、阻燃、接头形式、最小带轮直径和单卷长度等未提供数据，应在获得技术数据表后再增加。
