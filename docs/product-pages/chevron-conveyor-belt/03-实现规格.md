# 实现规格

## 1. 实现目标

在现有 Next.js 多语言架构内，将花纹输送带页面从通用产品页升级为包含以下模块的完整详情页：

1. 面包屑；
2. 产品图片和双语首屏；
3. 应用说明；
4. 产品特点；
5. 常见花纹；
6. 技术参数；
7. 储运注意事项；
8. 产品专属询盘入口；
9. SEO metadata、hreflang 和 Product JSON-LD。

不得为该产品新建与现有路由平行的硬编码页面。内容应继续由统一产品数据模型驱动。

## 2. 路由与语言

- 路由继续使用 `app/[locale]/[[...path]]/page.tsx`。
- `locale` 仅允许 `en`、`zh`。
- 产品 slug 在两种语言下保持 `chevron-conveyor-belt`。
- 英文页语言为 `en`；中文页根文档语言为 `zh-CN`。
- 切换语言时保留分类和产品 slug。
- 带 `?product=chevron-conveyor-belt` 的询盘链接在语言切换时也应保留查询参数。

## 3. 数据模型扩展

当前 `Product` 类型不足以承载花纹、储运说明、图片和 SEO。建议采用兼容扩展，避免破坏其他产品：

```ts
export type LocalizedMedia = {
  src: string;
  alt: string;
  width: number;
  height: number;
};

export type ProductSeo = {
  title: string;
  description: string;
};

export type Product = {
  slug: string;
  name: string;
  category: string;
  eyebrow: string;
  summary: string;
  description: string;
  features: string[];
  applications: string[];
  specifications: Specification[];
  patterns?: string[];
  precautions?: string[];
  media?: LocalizedMedia[];
  seo?: ProductSeo;
  sourceUrl?: string;
};
```

如果后续产品都需要不同的长正文，建议把本地化内容从 `lib/products.ts` 拆分到按产品组织的数据文件中；本次可以先保持现有结构，减少迁移范围。

## 6. 页面组件要求

### 6.1 产品首屏

- 桌面端采用图片与摘要双栏；移动端单列。
- 主图必须有本地化 `alt`，不能使用 CSS 背景承载唯一产品图。
- 主按钮指向当前语言的 `/request-quote?product=chevron-conveyor-belt`。
- 摘要附近展示“最终规格按应用确认”的短提示。

### 6.2 特点、花纹和参数

- 特点使用语义化 `ul/li`。
- 常见花纹优先使用六张真实局部图片；图片不足时使用文本卡片，不能生成看似真实的规格图。
- 参数使用 `dl/dt/dd` 或语义化表格。
- 数值和单位之间采用一致格式，如 `300–800 mm`、`0–40°`。

### 6.3 储运说明

- 独立于产品卖点展示，标题明确为 Handling and storage / 运输与储存。
- 不要把储运注意事项写入 features 数组。

### 6.4 询盘

- 首期可以沿用邮件询盘，但邮件正文应加入产品专属字段。
- 后续安全表单不得在客户端暴露邮件服务密钥。
- 用户从产品页进入询盘时，产品名称应按当前语言显示，同时传递稳定 slug。

## 7. Metadata 与结构化数据

`generateMetadata` 应优先使用 `product.seo`：

```ts
const title = product?.seo?.title || product?.name || fallbackTitle;
const description = product?.seo?.description || product?.summary || fallbackDescription;
```

Product JSON-LD 至少包含：

```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "localized product name",
  "description": "localized summary",
  "image": ["absolute approved image URL"],
  "brand": { "@type": "Brand", "name": "OVBEL" },
  "manufacturer": { "@type": "Organization", "name": "Shandong Respower Industrial Co., Ltd." },
  "url": "localized canonical URL"
}
```

没有真实价格和库存时，不添加虚假的 `offers`。JSON-LD 内容必须与可见页面一致。

## 8. 性能与无障碍

- 主图使用 Next.js `Image` 并提供准确宽高，避免布局偏移。
- 首屏主图可 `priority`，其余图片延迟加载。
- 所有花纹不能仅通过图片区分，应同时显示文本名称。
- 正文与背景对比度满足 WCAG AA。
- 键盘用户可以访问图片查看和 CTA。
- 移动端参数表不得产生不可控的横向溢出。

## 9. 推荐实施顺序

1. 获得并整理原产品图片；
2. 扩展 `Product` 类型和中文覆盖类型；
3. 更新英文及中文产品数据；
4. 抽取或扩展 `ProductPage` 的详情模块；
5. 增加产品专属询盘字段；
6. 增加 SEO 和 JSON-LD；
7. 完成双语、响应式、构建和 Cloudflare OpenNext 验证。
