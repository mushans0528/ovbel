# 验收清单

## 1. 内容事实

- [ ] 英文名为 `Chevron Conveyor Belt`，中文名为“花纹输送带”。
- [ ] 页面将 `0–40°` 标记为参考倾角，而不是无条件保证。
- [ ] 带芯完整展示 CC、CP、NN、EP 及其材料全称。
- [ ] 带宽为 `300–800 mm`。
- [ ] 花纹高度为 `5 / 10 / 15 / 20 mm`。
- [ ] 六类花纹名称在中英文之间一一对应。
- [ ] 四项原站特点均已覆盖，包括排水性能。
- [ ] 储运模块覆盖清洁、日晒、雨雪、化学品和一米热源距离。
- [ ] 页面没有补写未经确认的覆盖胶等级、强度、温度或认证。
- [ ] 所有新增行业应用或营销句均已由业务负责人审核。

## 2. 多语言

- [ ] 英文 URL 正常返回 200。
- [ ] 中文 URL 正常返回 200。
- [ ] `/en/...` 页面 `<html lang="en">`。
- [ ] `/zh/...` 页面 `<html lang="zh-CN">`。
- [ ] 语言切换保持当前产品 slug。
- [ ] 语言切换保留有意义的查询参数。
- [ ] 产品名称、正文、参数标签、储运提示和按钮均已本地化。
- [ ] 中文页面没有混入面向用户的英文占位文案。
- [ ] 英文和中文页面的信息量基本一致。

## 3. 页面与交互

- [ ] 面包屑链接均携带当前语言前缀。
- [ ] 主图有正确的本地化 alt。
- [ ] 花纹类型即使没有图片也能通过文本识别。
- [ ] 参数在 320 px 宽度下不产生不可用的横向滚动。
- [ ] CTA 可由键盘访问，并有清晰焦点样式。
- [ ] 询盘页正确预填产品并保留稳定产品 slug。
- [ ] 邮件或表单正文包含产品专属需求字段。
- [ ] 不存在无效图片、空链接或跳回无语言前缀路径的链接。

## 4. SEO

- [ ] 每种语言有独立 title 和 description。
- [ ] canonical 指向当前语言 URL。
- [ ] `en`、`zh-CN` 和 `x-default` hreflang 相互对应。
- [ ] Open Graph 标题、描述、URL 和图片正确。
- [ ] Product JSON-LD 与页面可见内容一致。
- [ ] 没有在 JSON-LD 中虚构价格、库存、评分或评论。
- [ ] 主图 URL 为可公开抓取的绝对 HTTPS URL。

## 5. 素材与权利

- [ ] 产品图来自公司可证明的可信来源。
- [ ] 产品负责人确认图片与本产品匹配。
- [ ] 未使用其他供应商搜索结果图片。
- [ ] 图片优化后仍保留母版。
- [ ] 所有发布图片均记录来源和权利主体。

## 6. 技术验证

- [ ] TypeScript 检查通过。
- [ ] `npm run build` 通过。
- [ ] Cloudflare OpenNext build 通过。
- [ ] 英文与中文产品页在桌面、平板和手机断点测试通过。
- [ ] 页面无阻断性浏览器控制台错误。
- [ ] 图片没有明显布局偏移。
- [ ] Lighthouse 或同类检查未发现严重的 SEO、性能和无障碍问题。
