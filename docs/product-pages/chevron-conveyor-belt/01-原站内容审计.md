## 3. 原站事实清单

### 3.1 应用

适用于在 `0–40°` 倾角下输送或包装粉状、颗粒状和块状物料，其表面花纹用于减少物料向下滑落。

注意：`0–40°` 是原站给出的参考范围。实际允许倾角会受物料、含水率、粒径、流动性、花纹形状与高度、带速和装载方式影响，页面必须避免表达为无条件保证值。

### 3.2 特点

原站列出四项特点：

1. 防滑；
2. 防滑花纹与上覆盖胶整体硫化；
3. 花纹形状、角度和间距经过设计；
4. 具有良好的排水性能。

原英文使用了 `anti-slip spikes`。新站建议采用工业输送带语境更自然的 `profiles` 或 `cleats`，不要沿用 `spikes`。

### 3.3 常见花纹

原站列出：

- Herringbone：人字形；
- Figure 8：8 字形；
- Fishbone：鱼骨形；
- U-shaped：U 形；
- Cylindrical：圆柱形；
- Hemp-faced：麻面。

原站同时说明可以根据用户要求设计花纹。

### 3.4 规格

| 参数 | 原站数据 | 规范化表达 |
|---|---|---|
| 带芯材料 | CC、CP、NN、EP 等 | Cotton canvas (CC), polyester-cotton (CP), nylon (NN), polyester (EP) |
| 带宽 | 300–800 mm | Reference belt width: 300–800 mm |
| 花纹高度 | 5、10、15、20 mm | Profile height: 5 / 10 / 15 / 20 mm |
| 参考倾角 | 0–40° | Reference inclination: 0–40° |
| 花纹定制 | 支持 | Pattern geometry can be designed to requirement |

原页面的 `Band width` 应规范为 `Belt width`。

### 3.5 储运注意事项

原站要求：

- 运输和储存期间保持输送带清洁；
- 避免阳光直射；
- 避免雨雪；
- 避免接触酸、碱、油和有机溶剂；
- 与加热装置保持至少一米距离。

页面应将这些内容表达为通用储运提示，不应替代针对具体胶料和项目的正式技术数据表或安全说明。
