## 2. 组件复用
| 组件 | 用途 | 是否修改 |
|---|---|---|
| `ProductDetailPage` | 详情页主框架，数据驱动 | 否 |
| `ProductGallery` | 主图库（点击全屏灯箱，键盘 Esc/左右） | 否 |
| `ZoomableImage` | 规格表图等内嵌图的点击放大（无放大镜图标） | 否 |

| `InquiryForm` | 询盘表单，自动预填产品名与询盘条目 | 否 |

## 3. 路由与 SEO
- 详情页路由：`/products/conveyor-belts/anti-tear-conveyor-belt`（en）/ `/zh/products/conveyor-belts/anti-tear-conveyor-belt`（zh），由既有通用路由处理，无需修改。
- `canonical` / `hreflang`（en, zh-CN, x-default）/ `Open Graph` / `Product JSON-LD` 由既有组件基于 `seo` 自动输出。
- 不含 `offers` / `aggregateRating`（不虚构价格/库存/评分）。

## 4. 多语言与查询参数
- EN/ZH 信息量一致（eyebrow/summary/description/applicationIntro/featureHeading/features/applications/specifications/patterns/precautions/inquiryChecklist/seo 全部对齐，数量一致）。
- 语言切换保持当前产品 slug 与询盘条目（既有 `getProducts(locale)` 实现）。

## 5. 关联产品
- 同一分类（`conveyor-belts`）其它产品（chevron / elevator / rough-top / sidewall / solid-woven / white / polyester / steel-cord）自动作为"相关产品"渲染。
