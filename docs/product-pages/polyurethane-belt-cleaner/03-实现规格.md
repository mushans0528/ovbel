# 03 — 实现规格

> 与现有 OVBEL 产品详情页实现保持一致，仅扩展 `lib/products.ts` 的数据模型；未新增组件、未新增路由。

## 1. 数据模型扩展

### 1.1 变更对象
- `lib/products.ts`：**新增** `polyurethane-belt-cleaner` 条目（EN，位于 `impact-bed` 之后、`elevator-buckets` 之前）+ `zhProducts["polyurethane-belt-cleaner"]`（ZH，位于 `impact-bed` 之后、`elevator-buckets` 之前）。

### 1.2 字段填充

| 字段 | 是否填充 | 来源 |
|---|---|---|
| `slug` / `name` / `category` | 是 | 原站栏目名与分类约定（`conveyor-components`） |
| `eyebrow` / `summary` / `description` | 是 | 原站“DB-HPU Primary Belt Cleaner”描述，编辑性改写 |
| `features` | 是 | 原页明确的 5 项特点，补充安装位置与分段选型说明 |
| `applications` | 是 | 基于矿山、煤炭、水泥、回收、港口等通用场景改写 |
| `specifications` | 是 | 原页文字参数（带宽、带速、温度、湿度）+ 型号/材料/安装/张紧/分段选型 |
| `patterns` | 否 | 本产品为单一型号，无花纹/系列分支，故未填充 |
| `precautions` | 是 | 行业通用安装、张紧、检查、储存规范，编辑性改写 |
| `inquiryChecklist` | 是 | 围绕事实的询盘要素 |
| `layers` | 是 | 基于产品结构推断的三层结构（刮刀/支撑管/张紧组件） |
| `seo` | 是 | title / description |
| `sourceUrl` | 是 | https://www.respowerbelt.com/h-col-126.html |
| `media` | 是 | 5 张真实 webp（3 张图库 + 2 张技术图） |

### 1.3 数字规格处理
- 带宽 450–2400 mm、带速最高 3.5 m/s、温度 −40~90 °C、湿度 ≤15% **均来自原页文字**。
- 选型表以 `technicalImages` 图片形式保留，**未在规格中逐格转录**，避免误读。
- 刮刀硬度、弹簧规格、支架尺寸、认证等原站未给出数值，**未在页面中编造**。

## 2. 自动同步的能力

由于站点采用统一数据驱动渲染：
- 分类页 `/products/conveyor-components` 自动出现该产品卡片；
- 产品卡片使用 `media.cover`、`summary`、`eyebrow`；
- 相关产品使用同分类其他产品；
- 询盘表单预填 `product=polyurethane-belt-cleaner`；
- `ProductDetailPage` 自动输出 canonical、hreflang（en / zh-CN / x-default）、Open Graph、Product JSON-LD。
