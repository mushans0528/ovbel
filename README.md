# OVBEL

OVBEL is a planned B2B website for industrial machinery parts, conveyor products, power-transmission components, rubber products, mining spares, motors, and drive equipment.

Planned domain: [ovbel.com](https://ovbel.com)

## Project documents

- [Website implementation plan](docs/OVBEL网站开发实施方案.md)
- [Existing content audit and development requirements](docs/现有网站内容盘点与开发需求文档.md)
- [Logo concept](assets/brand/ovbel-logo-concept-v1.png)

## Initial scope

- Six product categories
- Two initial products per category
- Twelve product detail pages
- English-first content with multilingual CMS support
- Next.js and TypeScript frontend
- Sanity content management
- GitHub source control
- Cloudflare Workers deployment

## Status

Planning and brand exploration. Application scaffolding has not started yet.
